# Ortigia

A survival-and-trade maze game set in the street labyrinth of Ortigia (Siracusa, Sicily).
TypeScript + Vite + HTML5 Canvas, no backend. Works with keyboard and touch.

```bash
cd ortigia
npm install
npm run dev        # open the printed URL (also reachable from a phone on the same Wi-Fi)
npm run build      # static build in dist/
npm run test:sim   # headless check: graph connectivity + movement rules
```

Every tunable number lives in [`src/config.ts`](src/config.ts).

## Map data

The street graph in `src/map/ortigia-map.json` is generated by `scripts/build-map.ts`
from OpenStreetMap data. It parses the data, cuts streets to the island coastline,
splits them at intersections, merges close junctions, drops short dead-end alleys,
keeps the largest connected network, adds the bridges as exits, and opens one-way
streets where needed so the player can never get trapped.

**Using real OSM data** (pick one, then run `npm run map:build`):

- `npm run map:fetch` downloads from the Overpass API into `data/ortigia.overpass.json`, or
- export an area from openstreetmap.org (Export → Manually select a different area) and save it as `data/ortigia.osm`.

Until then the build falls back to `data/ortigia-approx.overpass.json`. That file is a
**hand-traced approximation** (`npm run map:approx`), and the game shows a notice
instead of the OSM attribution while it is in use. Once the map is rebuilt from OSM,
"© OpenStreetMap contributors" is shown.

Map build parameters (merge distances, dead-end length, bridges, bbox) are in `MAP_BUILD` in `src/config.ts`.

Add `?debug` to the URL to show node ids.
